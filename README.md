# Maincrafts Technology Internship – Task 4

## Finite State Machine (FSM) Projects

This repository contains the Verilog HDL implementation and simulation of Finite State Machine (FSM) projects completed during **Task 4** of the **Maincrafts Technology Internship**.

### Projects
- Mealy FSM
- Moore FSM
- Traffic Light Controller
- Sequence Detector (1011)
- Vending Machine FSM
- Password Lock FSM

### Tools Used
- Verilog HDL
- EDA Playground
- Verilator
- EPWave
